交互行为规则

实现与验收对照

触发用户操作系统行为反馈
设备状态点击“读取设备状态”仅 USB 可读取。通过现有 `0x13 / S3R v1` 请求状态；仅接受匹配 request ID、完整分片、总长度与 CRC 正确的 `0x11 / kind 0x04` 响应。读取中；成功后显示读取时间。校验失败时保留上一次有效摘要并显示错误。
能力判断状态读取完成只读取 `ai_keyboard.config_status.v1` 的 `capabilities.semantic_actions`、`ptt_hotkey` 与 `edit_ptt_hotkey`；字段缺失、未知或 false 都不推断为支持。普通语义动作和 PTT 分别显示“可映射”或“设备未确认”。灯光与音乐律动始终显示“需要设备合同”。
前台应用规则选择带 Bundle ID 的已发现应用为当前配置档保存一条 `ProfileActivationRule`。相同 Bundle ID 的已启用规则不可重复。显示规则已启用或具体校验原因。
自动同步规则命中后 750 ms 内没有新的前台应用匹配仅在存在可写通道、没有同步进行且配置有效时发送最后一次匹配的配置档；继续使用 USB 优先和确认回执校验。发送中、已确认或具体失败原因；失败保留脏状态。
立即同步点击“立即同步”取消等待中的自动同步，发送当前版本一次；不与已有同步并发，也不跨通道回退。同步状态替换等待状态。
输入预设选择内建或自建文本、组合键预设映射时复制预设当前内容。内建组合键包括剪切、删除、回车、聚焦搜索和切换输入法。显示规范组合键；修改预设不改写已映射的按键。
喝水提醒设置 1–1440 分钟的间隔默认 30 分钟；仅在实际创建或更新提醒成功后更新通知状态。成功、权限拒绝或创建失败的具体结果。
屏幕清洁执行“屏幕清洁”显示 EasyMacBord 自身的全屏黑色遮罩；Esc 或关闭按钮退出，不承诺禁用物理键盘。遮罩显示与退出。
清空废纸篓执行“清空废纸篓”先显示本机确认；用户确认后才请求 Finder 清空废纸篓，取消不执行。确认框及执行结果；不把取消写成成功。
更新检查点击“检查更新”读取公开 Release 列表；正式包忽略预发布，Beta 包包含预发布。只显示 Release 信息及带对应 SHA-256 的 arm64 DMG 外部链接；所选链接交由默认浏览器打开。检查结果或失败原因；应用内不显示“已更新”，不下载 DMG 或改写应用包。

Toast 规则：成功显示约 3 秒，警告约 5 秒，错误保留到用户关闭或下一次相关操作；同时最多三条。长应用名、规则名、动作名和状态字符串单行截断，悬停或辅助功能标签提供完整值。所有状态同时提供文字，不只依赖颜色。
