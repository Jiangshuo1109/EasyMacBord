# EasyMacBord T02 UI 改造实施方案（基线）

**版本：** v0.1 T02 UI 改造基线
**适用范围：** EasyMacBord macOS 26+ Apple Silicon 客户端

> 本文件记录 T02 的四页导航和三栏编辑基线。T04 已改为独立动作库、宏键盘编辑、设置/关于与更新后的权限模型；实现和验收以 `T04桌面体验与动作中心设计说明.md` 为准。本文件不应作为 T04 当前界面说明。

## 目标

在不修改固件、S3C v1 协议和 USB 优先路由的前提下，将当前界面整理为四页导航和三栏配置编辑器。界面只展示运行时已知信息；设备尚未提供的数据明确标为“未读取”。

## 页面与组件职责

| 页面或组件 | 负责内容 | 不负责内容 |
|---|---|---|
| 根窗口与侧栏 | 默认 `1280 x 800`、最小 `1120 x 720`、四页导航、当前设备与配置档摘要 | 在侧栏编辑动作、展示 UUID 或绝对路径 |
| 状态总览 | 设备、配置档、同步、权限摘要；11 个控制事件预览；本机动作记录 | 推断固件版本、证明固定文本或组合键已经由设备执行 |
| 配置档选择器 | 在编辑区顶部选择和新建本地配置档 | 自动同步或删除未确认配置 |
| 配置档编辑区 | 8 个键和单旋钮左转、按下、右转的选择与预览 | 生成多枚旋钮或额外控制件 |
| 设置检查器 | 动作类型分段控件、登记/选择本机动作、保存提示、测试入口 | 显示 UUID、安全书签或绝对路径 |
| 设备与同步 | 当前连接、同步结果、上次确认、回执摘要、未知设备字段 | 将蓝牙配置通道称为 HID，或伪造设备能力 |
| 权限 | 系统权限状态、重新检查和跳转系统设置 | 绕过、修改或模拟系统授权 |

## 数据与状态

- 复用现有配置档、控制事件、动作登记、连接、权限和同步状态模型。
- 同步历史在本地保存最后一次有效确认和最近失败原因。本次失败只更新失败状态，保留上次确认时间与回执摘要。
- 固件版本、备用通道、能力使用可扩展的“已读取 / 未读取”状态；本期所有未通过协议读取的字段均显示“未读取”。
- 动作记录只接收设备 Host Action 的执行结果和手动测试结果，最多保留最近 20 条；记录不保存 UUID、路径、用户文本或设备唯一标识。

## 实施顺序

1. 调整主窗口尺寸和导航枚举，移除独立“本机动作”页面入口，将动作登记表单放入配置档检查器。
2. 将配置页改为固定三栏：主侧栏、顶部配置档选择器与新建命令、11 个控制事件网格和右侧检查器；补齐应用、网址、快捷指令、系统动作登记入口。
3. 更新状态总览和设备与同步页，接入同步历史、回执摘要、未知设备信息和动作记录。
4. 限制测试入口：仅已登记本机动作可测；固定文本与组合键显示实体设备验证提示；锁屏动作增加二次确认。
5. 统一视觉细节、截断策略、禁用态和无连接态，按原型检查四页在两种窗口尺寸下的布局。

## 验收与非目标

- 在 `1280 x 800` 和 `1120 x 720` 截图验收四页，确认标题、按键卡片、检查器、底部操作区没有重叠、溢出或误导性状态。
- 覆盖未连接、连接中、同步中、确认、失败、无本机动作、权限未授予、长名称和“未读取”字段。同步失败截图必须同时看到上次确认记录和本次错误。
- 自动化测试补充配置档新建、同步确认历史保留、手动测试记录和未知设备状态；既有协议、序列化和通道路由测试必须保持通过。
- 本期不新增设备状态读取协议，不将界面完成当作真机联调完成，也不支持移动端或低于最小窗口宽度的布局。
