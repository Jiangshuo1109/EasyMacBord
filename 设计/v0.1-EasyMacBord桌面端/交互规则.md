# 交互规则

| 触发 | 用户操作 | 系统行为 | 反馈 |
|---|---|---|---|
| 配置档 | 选择配置档 | 切换当前编辑对象，不立即同步 | 标题更新 |
| 按键映射 | 选择一个按键 | 打开该按键的动作编辑区 | 选中描边 |
| 本机动作 | 选择应用 | 创建或复用本机 UUID 映射 | 显示动作名称，不显示路径 |
| 同步 | 点击同步 | 编码 JSON，按 USB 优先或 BLE 发送 | “正在确认” |
| 保存确认 | 回执 bytes/CRC 匹配 | 更新设备已保存状态 | “已确认”短提示 |
| 保存确认 | 回执失败或不匹配 | 保留失败原因，不覆盖上次确认状态 | “设备未确认保存” |
| 权限 | 点击重新检查 | 读取可公开检查的系统权限状态 | 逐项更新 |
| Host Action | 收到合法 UUID | 查询本机登记项后执行 | 最近执行记录更新 |
| Host Action | UUID 无映射或格式无效 | 不执行任何动作 | 记录失败类别 |
| 连接 | USB 与 BLE 都存在 | USB 作为活动事件通道 | 连接状态显示 USB |

Toast 位于窗口右下角：成功 3 秒，警告 5 秒，错误直到用户关闭或下一次操作。最多同时显示 3 条。按键标题和路径类文本在一行内截断，悬停显示完整值。
