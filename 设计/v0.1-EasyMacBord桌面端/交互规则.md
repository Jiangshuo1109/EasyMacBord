# 交互规则

| 区域 | 触发 | 系统行为 | 反馈与边界 |
|---|---|---|---|
| 主窗口 | 点击菜单栏“进入设置”、Dock 或应用重新激活 | 恢复已有主窗口或显示一个主窗口 | 三个入口使用同一协调器；不得生成重复主窗口 |
| 全局导航 | 点击主导航项 | 切换状态总览、配置档、动作库、设备与同步、权限 | 设置和关于固定在侧栏底部；设备摘要与产品品牌分开显示 |
| 配置档 | 选择已有配置档 | 切换当前编辑对象，不立即同步 | 标题、侧栏和映射区同时更新 |
| 配置档 | 点击“新建配置档” | 创建一份可编辑的本地配置档并选中 | 先保存到本地；未同步前显示“本地更改已保存” |
| 控制件 | 点击 `4 x 2` 键帽或旋钮左转、按下、右转 | 将控制件设为当前编辑对象 | 键帽、旋钮选择区尺寸固定；中栏保持选中描边，右栏显示对应设置 |
| 动作类型 | 切换分段控件 | 更换本机动作、固定文本、键盘组合键或禁用的编辑方式 | 切换为禁用时清除设备侧值并显示“未设置” |
| 本机应用 | 在动作库点击“从本机应用登记” | 读取常规应用程序目录并显示可搜索候选项；用户选择后才登记动作 | 候选项只显示名称、图标和来源；不显示绝对路径；无候选项时可返回并改用手动选择 |
| 直接工具 | 在动作库选择截图与录屏、锁定屏幕、保持唤醒、壁纸、音量、隐藏前台应用或 Apple Music 控制 | 仅在本地创建或复用动作登记项 | 工具必须登记后才可绑定控制件；截图与录屏只打开系统界面，保持唤醒只防闲置显示器休眠 |
| 快捷指令模板 | 在动作库选择深色模式、屏保、键盘清洁、隐藏桌面文件/Dock、分屏、显示器/键盘亮度模板 | 打开预填标题的快捷指令登记表单 | 用户填写已有快捷指令名称并完成系统授权；应用不创建快捷指令、不写 Finder/Dock 偏好 |
| 输入预设 | 在动作库新建、编辑或删除固定文本、组合键预设 | 保存本机预设；选择时复制当前值给控制件 | 编辑或删除预设不回写既有控制件；预设不生成设备 UUID |
| 组合键录制 | 点击开始录制并按下组合键 | 将支持的按键与修饰键规范化为现有协议格式 | 只按修饰键、Fn、媒体键或未映射键位不保存，提示无法记录 |
| 本机动作 | 在动作库登记应用、网址、快捷指令或系统动作 | 仅在本地创建或复用动作登记项 | 显示动作名称和类型；不显示 UUID、安全书签或绝对路径 |
| 本机动作 | 选择已登记动作 | 配置引用该登记项的 UUID | 设备配置仅写入 UUID；界面不展示 UUID 值 |
| 测试动作 | 测试已登记的本机动作 | 应用直接调用本机执行器，并记录结果 | 只允许本机动作测试；固定文本和键盘组合键提示通过实体设备验证 |
| 测试锁屏 | 点击测试“锁定屏幕” | 显示二次确认，确认后才执行 | 取消不执行，也不写入动作记录 |
| 测试壁纸与音量 | 点击已登记的壁纸或音量工具 | 使用用户选图或当前默认输出执行 | 壁纸可能改变桌面背景，音频输出不支持时明确失败；两者不改用其他目标 |
| 测试 Apple Music | 点击已登记的 Apple Music 工具 | 请求系统自动化执行对应命令 | 自动化拒绝、Music 不可用或命令错误时记录失败；命令发出不等于确认已经播放 |
| 同步 | 点击“同步当前配置” | 编码 JSON，USB 优先发送；仅 USB 不存在时使用蓝牙配置通道 | 同步期间显示“正在确认”，重复点击不可用 |
| 保存确认 | 回执的 phase、ok、saved、bytes、CRC 全部匹配 | 保存本次确认时间和回执摘要 | 显示“已确认”；摘要不包含配置正文、路径或 UUID |
| 保存确认 | 写入失败、超时或回执不匹配 | 记录本次失败，但不覆盖上次确认记录 | 显示“设备未确认保存”和可公开的失败原因 |
| 设备信息 | 打开设备与同步 | 读取连接和同步模型中的已知信息 | 无状态读取协议的固件、备用通道、能力均显示“未读取” |
| 辅助功能 | 点击请求权限、重新检查或应用重新激活 | 请求或检查系统辅助功能状态 | 用户未明确请求时不弹出提示；不在应用中伪造已授权状态 |
| 自动化 | 首次执行 Apple Music 或快捷指令 | 根据系统结果更新该能力状态 | 没有统一全局预检；命令提交不等于目标动作已完成 |
| 设置 | 切换菜单栏显示或开机启动 | 保存偏好；开机启动请求系统登录项服务 | 菜单栏默认开启，开机启动默认关闭；关闭菜单栏后 Dock 仍可恢复主窗口 |
| Host Action | 收到合法 UUID | 查询本地登记项后执行 | 仅将已尝试且可确认结果的动作写入“本机动作记录” |
| Host Action | UUID 无映射或格式无效 | 不执行任何动作 | 记录失败类别，不显示 UUID 原文 |
| 双通道 | USB 与蓝牙配置通道都可用 | USB 为优先写入和活动事件通道 | USB 失败不自动改走蓝牙配置通道 |

## 文本与状态

- 普通成功提示显示 3 秒；警告显示 5 秒；错误保留至用户关闭或下一次相关操作。最多同时显示 3 条。
- 按键名称、动作名称和配置档名称单行截断，悬停显示完整名称。长名称不得改变按键卡片和检查器的固定布局。
- 状态不用颜色单独表达：同步、权限和失败信息必须同时提供文字和图标或控件状态。
- “未读取”表示当前协议没有提供该数据，不等同于无固件、无能力或连接失败。
- 直接工具、快捷指令模板和输入预设均由动作库统一维护。工具名称过长时与其他动作名称一样单行截断，悬停显示完整名称。
