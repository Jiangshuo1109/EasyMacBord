# EasyMacBord 桌面端需求总结

**版本：** v0.1
**载体：** macOS 26+ 独立菜单栏应用
**设计取向：** 状态总览优先，使用原生 macOS 结构与克制的玻璃材料

## 用户与场景

目标用户是已经拥有 EasyInput V2.0 的 Apple Silicon Mac 用户。典型场景是工作开始前切换“日常”配置档，在设备连接后为按键设置应用、网页、快捷指令、固定文本或组合键；同步后通过实体输入触发本机动作。

## 本版做什么

- 菜单栏中查看连接与配置档，打开设置。
- 状态总览中查看设备、同步、权限和最近执行记录。
- 配置档中查看并编辑 8 键与旋钮动作。
- 通过 USB 或 BLE 同步，且只在收到保存确认后显示成功。
- 对 Host Action UUID 在本机查找已登记动作并执行。

## 本版不做什么

- AI、语音、Wi-Fi 音频、音乐律动、DDC 和云同步。
- Maker 固件、硬件、烧录和设备身份调整。
- 未经用户选择的应用启动或自动化。

## 关键决定

- 主窗口首页不是按键编辑器，而是状态总览；按键编辑放在独立“配置档”页。
- 设备卡片、同步标签等高优先级信息使用玻璃材料；表单和按键映射保持清晰的实体边界。
- USB 与 BLE 同时存在时，USB 是活动事件通道；失败状态必须能看见具体层级。
- Host Action 只显示动作名称和结果，不在界面日志中显示 UUID 或本机路径。

## 交付物

- `主界面.html`：主窗口正常态。
- `全状态设计参考.html`：加载、空、无结果、权限拒绝、同步失败和部分可用状态。
- `交互规则.md`：操作到反馈的规则表。
