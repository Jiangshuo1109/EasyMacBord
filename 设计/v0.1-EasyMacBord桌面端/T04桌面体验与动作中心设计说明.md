# T04 桌面体验与动作中心设计说明

**状态：** 已实现；本文件仍是人工验收的设计依据，不代表两种目标窗口尺寸、Dock 行为、本机工具或真机联调已经通过。

## 窗口与侧栏

- Dock、菜单栏和应用重新激活使用同一主窗口恢复路径。任何入口的结果都是显示一个主窗口，而不是新建多份窗口。
- 侧栏顶部先展示 EasyMacBord 图标和名称，再展示单独的设备连接摘要。产品名称不复用设备名称。
- 主导航依次为状态总览、配置档、动作库、设备与同步、权限。设置、关于置于侧栏底部，和工作区导航区分开。
- 工具栏保留页面名称，内容区不再放同名大标题。窗口尺寸基线仍为 `1280 x 800` 和 `1120 x 720`。

## 配置档与动作库

- 配置档编辑中间区是 `4 x 2` 的实体宏键盘式布局，右侧是旋钮。键帽及旋钮左转、按下、右转都可选择，控件尺寸不因名称增长而变化。
- 按键映射显示简短动作名称和类型；已登记应用在映射中显示应用图标。图标仅从可访问的已登记目标运行时解析，失效时回退为通用应用图标。
- 动作库独立维护 Host Action 与输入预设。Host Action 包括应用、网址、快捷指令、直接系统工具；输入预设包括固定文本和组合键。
- 输入预设应用到控制件时复制标题和值。预设编辑、删除不会追溯修改已有控制件，不改变设备端 JSON 或 UUID 合同。
- 组合键录制由用户先点击明确的录制控件，再按实际组合键完成。控件只接收自身窗口内的按键；不做全局监听。

## 设置与权限

- 菜单栏显示默认开启。关闭后不影响 Dock 恢复主窗口。
- 开机启动默认关闭。用户主动开启后才调用系统登录项服务，若系统需要确认，页面展示待确认而不是“已开启”。
- 关于页读取包内版本、构建号和架构，明确这是内部 ad-hoc 测试构建。
- 辅助功能在用户点击请求后唤起系统授权，并在应用重新激活或手动刷新时复查。自动化以第一次相关动作的系统结果为准。
- 当前截图与录屏操作只打开系统截图面板，不申请屏幕录制权限。应用内采集功能不属于 T04。
