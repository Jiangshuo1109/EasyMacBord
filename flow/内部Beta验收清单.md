## 配置保存与硬件矩阵

先完成一项最小配置写入。发送 `0x10 / S3C` 后，异通道的 `0x03` 只能作为无关回执忽略；只接受同一写入通道发回、且 `saved`、`bytes` 和 CRC 均一致的 `0x03`。冷重连后再次读取或验证保存结果。现有协议没有事务 ID，同通道、同内容的旧回执仍须作为现场风险记录。未成功前不开始实体输入矩阵。

| 项目 | 现场通过条件 | 当前结论 |
|---|---|---|
| 最小 USB 写入 | `0x10 -> 0x03` 同通道确认，`saved/bytes/CRC` 一致，冷重连后仍有效 | UNKNOWN |
| HW-01 USB-only | 已确认配置下，实体按键触发目标动作 | UNKNOWN |
| HW-02 BLE-only | BLE HID 和 BLE 配置通道均可用，实体按键触发目标动作 | UNKNOWN |
| HW-03 双连接 | 同一按键只执行一次，确认来源不跨通道 | UNKNOWN |
| HW-04 按下 | 单次按下只产生一次动作 | UNKNOWN |
| HW-05 松开 | 松开不额外触发动作 | UNKNOWN |
| HW-06 回归 | 复制、粘贴、组合键、固定文本仍正常 | UNKNOWN |
| HW-07 本机应用 | 已选测试应用实际打开 | UNKNOWN |

观察模式只用于报告到达和计数，不能作为 HW-03 至 HW-05 的通过依据。若控件映射或 NVS 内容未知，不执行试探性按键操作。
