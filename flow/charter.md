# 项目宪章

- **项目名：** EasyMacBord
- **目标：** 为 EasyInput V2.0 提供 macOS 26+ 的日常效率配置与本机动作执行工具。
- **本版做：** 菜单栏与 Dock 主窗口恢复、状态总览、配置档、独立动作库、8 键/旋钮映射、USB/蓝牙配置通道同步、本机动作与输入预设、权限状态、设置/关于和 arm64 ad-hoc DMG。
- **本版不做：** Maker 固件和硬件修改、烧录、AI/语音/Wi-Fi 音频、DDC、云同步和自动更新。
- **约束：** 开发板只保存 UUID；USB 优先；非法协议 fail closed；不记录个人路径、UUID、设备唯一标识或用户文本。
- **成功标准：** 全量 App 测试和 arm64 构建通过；签名校验通过；配置收到对应确认；七项真机矩阵逐项给出人工观察。
- **角色：** macOS 端负责配置、权限与执行；上游 Maker 负责既有设备协议和硬件；测试人员负责实物观察确认。
