# 联调记录

每次接入设备新增一节，按如下格式记录。不要粘贴完整 MAC、序列号、USB 拓扑、用户应用路径或原始日志。

## 模板

- **日期与应用版本：**
- **设备协议身份：** USB `VID/PID` 与蓝牙服务/特征是否匹配；PASS / FAIL / UNKNOWN
- **设备固件能力：**
- **连接方式：** USB-only / 仅蓝牙配置通道 / 双连接
- **配置确认：** bytes、crc16 是否匹配；结果 PASS / FAIL / UNKNOWN
- **可观察目标：** 计算器（Host Action）、TextEdit（固定文本、快捷键、复制/粘贴）
- **真机项目：** HW-01 至 HW-07 的人工观察和结果；未执行逐项标记 UNKNOWN
- **失败层：** 连接 / 写入 / 保存确认 / HID 消息 / 映射 / 权限 / 执行
- **未验证项：**
