# 决策记录

## 2026-08-26 · v0.1 使用 macOS 26+ 原生界面

- **决定：** 使用 SwiftUI/AppKit 和系统材料，最低版本设为 macOS 26，产物只支持 arm64。
- **原因：** 项目明确需要当前 macOS 的玻璃质感，且首批用户是 Apple Silicon 环境。
- **影响：** 不为 macOS 15 及更早版本提供降级界面。

## 2026-08-26 · 设备配置与本机映射分离

- **决定：** 设备端只接收 `host_action:<uuid>`；应用目标、安全书签和执行方式只保存在 Mac 本地。
- **原因：** 设备不应携带用户应用路径、名称、Bundle ID 或启动参数。
- **影响：** UUID 无本地映射时必须停止执行并提示用户。

## 2026-08-26 · 同步确认以设备回执为准

- **决定：** 只有 `0x11/kind=0x03` 或对应 BLE Status 的长度和 CRC 与本次 JSON 匹配时，才显示“已确认”。
- **原因：** “已发送”不能说明设备已持久化配置。
- **影响：** USB 写入失败不自动转 BLE；出现不匹配时保留失败证据。

## 2026-08-26 · v0.1 使用 ad-hoc 分发

- **决定：** 使用 `codesign -s -` 打包 DMG，不使用 Developer ID 或公证。
- **原因：** 当前是私有小范围测试，不引入开发团队或证书管理。
- **影响：** 发布说明必须告知 Gatekeeper 手动放行限制。
