# T05 动作与场景证据

本目录用于存放 T05 实际执行后的脱敏证据。设计稿、逻辑测试、界面观察和实体设备观察必须分别记录，不能相互替代。

2026-08-27 已完成隔离 Debug 构建的两种窗口尺寸界面观察，详见 [UI-验收-2026-08-27.md](UI-验收-2026-08-27.md)。该观察不构成设备、通知、Finder、更新下载或实体输入通过结论。

## 计划收集的证据

| 类型 | 最低内容 | 记录要求 |
|---|---|---|
| 逻辑测试 | 状态请求/分片/长度/CRC 校验、语义/PTT 门控、规则匹配、750 ms 防抖、内建组合键、提醒和本机确认 | 在测试输出和 `flow/进展.md` 记录命令、结果和日期，不在本目录保存日志副本 |
| 界面观察 | `1280 x 800` 与 `1120 x 720` 下的配置档台面、规则管理、状态失败、能力缺失、喝水提醒、清洁屏幕遮罩、废纸篓确认、更新检查结果 | PNG 仅显示界面状态；不得包含 UUID、应用绝对路径、安全书签、设备唯一标识、Release 下载 URL 或用户文本 |
| 更新检查 | 公开 Release 检查成功、无可用版本、网络失败三种界面状态；可用版本需显示 Release 信息、`arm64` DMG 与 SHA-256 外部链接 | 只证明界面与外部打开行为，不证明下载、校验、安装、替换或 Gatekeeper 放行 |
| 实体设备 | `0x13 / S3R v1` 请求、匹配 request ID 的 `0x11 / kind 0x04` 完整响应与 `semantic_actions` 实际观察 | 写入 `flow/integration-record.md`；不保存原始 HID 数据、MAC、序列号或 USB 拓扑 |

## 文件命名

- 界面截图：`YYYY-MM-DD-状态-宽x高.png`，例如 `2026-08-27-status-error-1280x800.png`。
- 截图旁的简短说明放入同名 `.md`，写明观察对象、窗口尺寸、构建版本和结果；不要复制敏感文本或链接。
- 若证据不合格、尺寸不符或来自错误构建，应删除该文件，并在 `flow/进展.md` 说明没有形成该项结论。
