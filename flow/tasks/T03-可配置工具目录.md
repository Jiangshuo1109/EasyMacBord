# T03 可配置工具与本机应用目录

## 目标

让用户在配置档检查器的动作库中，从当前 Mac 的常规应用程序目录选择应用，或登记可配置的本机工具，再映射给 8 个按键和旋钮的 3 个事件。设备端继续只保存 `host_action:<uuid>`，本任务不改动固件或协议。

## 范围

### 直接实现

| 项目 | 用户动作 | 边界 |
|---|---|---|
| 本机应用 | 搜索、刷新并选择已安装应用 | 只读扫描常规应用程序目录；列表不显示路径；选中后才保存安全书签 |
| 截图与录屏 | 打开系统截图界面 | 不直接截图、录屏或读取屏幕内容 |
| 锁定屏幕 | 锁定当前会话 | 手动测试必须二次确认 |
| 保持唤醒 | 启用或停用防闲置显示器休眠 | 不承诺合盖运行、阻止锁屏或阻止所有系统休眠 |
| 壁纸 | 用户选图后设置桌面背景 | 不扫描照片库；测试后由测试人员恢复原背景 |
| 音量 | 当前默认输出音量增减、静音 | 输出设备不支持时失败，不修改其他输出 |
| 隐藏应用 | 隐藏当前前台应用 | 不终止应用，不改动 Finder 或 Dock 偏好 |
| Apple Music | 播放/暂停、上一首、下一首 | 只支持 Apple Music，依赖自动化权限，不以命令发出推断实际播放 |

### 用户快捷指令模板

动作库提供预填标题的快捷指令登记入口。用户需要自行创建、维护和授权以下实际快捷指令：深色模式、启动屏保、键盘清洁、隐藏桌面文件、隐藏 Dock、分屏布局、调节显示器亮度、调节键盘亮度。

不得通过私有 API、写 Finder/Dock 偏好或假定显示器硬件能力来绕过这个边界。

## 实施项

- [x] 枚举用户、本地和系统应用程序目录的 `.app`，按 Bundle ID 去重，并为无 Bundle ID 的候选项提供稳定区分。
- [x] 在动作库提供搜索、刷新、选择和手动选择应用入口；候选项只显示名称、图标和来源。
- [x] 复用既有 `HostActionRegistry`：应用和工具登记后均生成或复用本机 UUID 映射，设备配置不增加字段。
- [x] 实现直接工具执行和可公开的失败反馈；不在常规日志中写应用路径、UUID、安全书签或用户选图路径。
- [x] 提供快捷指令模板入口，但不创建、编辑或自动授权用户的快捷指令。
- [x] 覆盖目录扫描、重复候选、工具标识和模板清单的纯逻辑单元测试。
- [ ] 在两种目标窗口尺寸完成人工界面检查；再执行 M-01 至 M-08 本机工具人工验收。
