# T04 桌面体验与动作中心

## 目标

在不改动 Maker 固件、GPIO、HID/GATT 描述符、Flash 分区、S3C v1 或 USB 优先路由的前提下，修复主窗口恢复路径，并将本机动作维护从配置检查器扩展为独立动作库。该任务只改变 Mac 端的界面、本地数据和权限交互。

## 实施范围

- 菜单栏、Dock 点击和应用重新激活通过同一协调器显示一个主窗口；不得因入口不同创建重复窗口。
- 侧栏顶部显示完整 EasyMacBord 品牌和独立设备摘要；内容区不重复窗口工具栏页面标题。
- 侧栏新增“动作库”，集中维护应用、网址、快捷指令、直接系统工具、固定文本预设和组合键预设；设置、关于位于侧栏底部。
- 已登记应用仍由安全书签定位。图标仅在运行时解析并显示在动作库、选择器和宏键盘键帽中；不持久化图标、路径或安全书签内容。
- 文本与组合键预设为本地便利数据。选中预设时把标题和值复制给控制件；预设编辑或删除不回写已有控制件，也不改变设备协议。
- 组合键录制只在用户明确开始录制且控件获得焦点后接收当前窗口按键。保存值使用固件既有格式；不支持的键位和仅修饰键给出反馈，不写入值。
- 配置档编辑区以 `4 x 2` 键帽和单枚旋钮表现 11 个控制事件。键帽尺寸固定，长名称截断并提供完整值提示。
- 菜单栏显示默认开启，开机启动默认关闭且仅在用户切换时调用登录项服务。关于页读取包内版本和构建信息。
- 辅助功能由用户明确请求并在应用重新激活时复查；自动化只显示首次相关执行后的结果。当前不显示或请求屏幕录制权限，因为截图与录屏动作仅打开系统截图面板。
