# T05 动作与场景

## 目标

以设备优先的 EasyInput 控制台扩展配置档自动切换、动作库和状态读取。T05 只扩展 Mac 端的前台应用规则、状态消费和同步调度；设备协议仍以当前 Maker 合同为唯一依据，不修改固件或硬件。

## 实施范围

- 配置档页使用 `4 x 2` 键盘与旋钮台面展示当前 Profile 的 11 个控制事件，并提供前台应用自动切换规则入口。
- 自动切换规则仅关联既有 Profile 与应用 Bundle ID；支持添加、启停、移除和重复规则拒绝，只保存配置档 ID、Bundle ID、应用名称和启用状态，不保存路径或安全书签。
- 设备语义动作使用 Maker 已有的 `voice_ptt_hold`、`edit_ptt_hold`、`select_all`、`copy`、`paste`、`undo` 值，不走 `host_action:<uuid>`。通用动作要求 `semantic_actions=true`，两种 PTT 动作还要求两个 PTT 字段已读取。
- 状态读取复用 Status HID v1：USB 已连接时以 `0x13` / `S3R v1` 请求，接收 `0x11 / kind 0x04` 分片状态响应。解析前必须验证 request ID、分片、总长度和 CRC；只消费 `ai_keyboard.config_status.v1` 中存在的字段。
- 前台应用规则命中后使用 750 ms 自动同步防抖。立即同步取消等待，只发送当前已保存配置版本；现有 USB 优先、失败不回退和保存确认要求保持不变。
- 动作库提供剪切、删除、回车、聚焦搜索和切换输入法五个内建组合键预设；喝水提醒范围为 1 至 1440 分钟、默认 30 分钟，通知状态只在动作实际执行后更新。
- 清洁屏幕遮罩可由关闭按钮或 Escape 退出，不拦截物理键盘。清空废纸篓必须先在本机确认；取消不执行，确认后才请求 Finder。
- 关于页可检查公开 GitHub Releases；Beta 包含预发布。应用只展示 Release 信息、可用的 `arm64` DMG 与对应 SHA-256 外部链接，并交由默认浏览器打开。ad-hoc 包继续由用户手动下载、替换和按 Gatekeeper 提示放行。
- 灯光和音乐律动在缺少新增、冻结并真机验证的设备合同前显示 `UNKNOWN / 不可用`，不发送推测命令。
