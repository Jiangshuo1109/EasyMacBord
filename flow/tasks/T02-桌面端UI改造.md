# T02 桌面端 UI 改造

## 目标

将 EasyMacBord 的桌面端改为四页导航和三栏配置页，在不修改固件、S3C v1 或 USB 优先路由的条件下补齐同步历史、未知设备状态和测试动作边界。

## 实施内容

- 主窗口默认 `1280 x 800`、最小 `1120 x 720`；导航只保留状态总览、配置档、设备与同步、权限。
- 配置页沿用主侧栏，编辑区顶部选择或新建配置档，中间编辑 8 键及单枚旋钮左转、按下、右转，右侧检查器登记或选择本机动作。
- 本机动作登记支持应用、网址、快捷指令和系统动作，不在界面显示 UUID、绝对路径或安全书签；固定文本和组合键只提示实体设备验证。
- 状态总览显示 11 个控制事件预览和本机动作记录；设备与同步显示上次确认、回执摘要、当前失败和“未读取”的设备字段。
- 蓝牙统一标为“蓝牙配置通道”；锁定屏幕测试增加二次确认。

## 验收

- 补齐配置档新建、同步历史保留、手动测试记录、未知设备信息的单元测试，既有协议和通道路由测试仍通过。
- 在 `1280 x 800` 和 `1120 x 720` 截图检查四个页面及未连接、同步中、确认、失败、无本机动作、权限未授权和长名称状态。
- 失败态必须保留上次确认信息；未知数据必须显示“未读取”；页面不出现独立本机动作导航或虚构硬件详情。
