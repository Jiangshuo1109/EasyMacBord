# 硬件联调与边界

## 不可修改的边界

EasyMacBord 是现有 EasyInput V2.0 的 macOS 消费端。本仓库不修改 ESP32-S3 固件、GPIO、BOOT、GPIO8 共享电源、Flash 分区、USB/BLE 名称、VID/PID、HID 描述符和自定义 GATT 定义。

正常模式 USB 是 HID，不是 CDC 串口。看不到串口不能作为设备失败结论。烧录、复位、`idf.py flash`、`esptool` 和设备识别不在本仓库工作流内。

## 联调前置

1. 使用已通过上游验证的 EasyInput V2.0 固件。
2. 记录设备是否能以 USB HID 或 BLE 被发现；不记录完整 MAC、序列号或 USB 拓扑。
3. 选择一个可观察的本机目标应用。
4. 同步后核对 `0x03` 确认的 bytes 和 CRC。

## 故障定位顺序

设备不可见 → 连接通道 → 配置写入 → 保存确认 → 能力状态 → Host Action 消息 → UUID 映射 → macOS 权限 → 目标应用执行。

任何一层没有证据时，保留现场并记录失败层；不重烧录、不手写 UUID、不通过重复同步制造“成功”。
