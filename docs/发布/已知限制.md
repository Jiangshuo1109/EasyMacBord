# 已知限制

- 当前构建基线为 Xcode 27.0 beta 6。正式版 Xcode 发布后，应使用正式工具链再次完成构建、测试和 DMG 签名验证。
- ad-hoc 签名只封存代码，不提供 Developer ID 身份、公证或跨机器无提示安装保证。
- USB 与蓝牙配置通道的协议实现以本地 Maker 参考工程为依据；本仓库尚未对实际设备完成联调。
- v0.1 不包含 AI、语音、Wi-Fi 音频、音乐律动、DDC、自动更新和云同步。
- T03 的应用目录读取和本机工具已通过单元测试、arm64 Release 编译和内部 DMG 签名校验；尚未取得新包的人工界面截图，M-01 至 M-08 也尚未形成实际观察结论。
- 应用目录仅用于让用户选择本机应用；未选择的候选项不保存，已选择应用移动或失效后必须重新选择。
- “保持唤醒”只防止闲置显示器休眠；不保证合盖继续运行，不替代系统锁屏，也不保证阻止所有系统休眠原因。
- 打开系统截图与录屏界面不等于已生成截图或录屏文件。应用不直接读取屏幕内容。
- 壁纸只接受用户主动选择的图片；测试会改变桌面背景，需由测试人员自行恢复。
- 音量控制只针对当前默认输出，输出设备不支持相应控制时应失败。隐藏应用不会退出应用，也不会改动 Dock 或 Finder 设置。
- Apple Music 控制仅支持播放/暂停、上一首和下一首，取决于 Music 是否可用及系统自动化权限；不支持其他播放器，也不把命令提交当作播放成功。
- 深色模式、屏保、键盘清洁、隐藏桌面文件、隐藏 Dock、分屏、显示器亮度和键盘亮度仅通过用户维护的 macOS 快捷指令接入。项目不写入私有偏好，也不调用私有显示器接口。
- GitHub 已通过 SSH 同步；仍应在每次发布后核对远端提交与本地提交一致。
