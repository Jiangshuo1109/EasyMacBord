# EasyMacBord 软件需求规格说明书

**版本：** v0.1 UI 改造、T03 可配置工具与本机应用（已实现，待人工验收）、T04 桌面体验与动作中心（已实现，待完整 UI 与实物验收）
**目标读者：** 产品负责人、macOS 开发人员、EasyInput 固件维护人员和真机测试人员

## 1. 背景与目标

EasyInput V2.0 可通过 USB HID 发送实体输入，并提供蓝牙配置通道写入配置；设备也可发送 Host Action UUID。用户需要在 Mac 上维护多个配置档，并把“打开应用”等本机动作绑定到实体控制件。设备不应持有应用路径、应用名称或启动参数。

本次改造的目标是提供可恢复的主窗口和清晰的动作维护入口：用户可查看真实连接与同步状态，编辑 8 个按键和单枚旋钮的三个事件，在独立动作库登记本机动作或维护文本、组合键预设，并在收到合法 UUID 时执行已登记的 Host Action。设备未上报的数据不作推断。

## 2. 功能需求

| 编号 | 需求 | 验收条件 |
|---|---|---|
| FR-01 | 主窗口入口和菜单栏状态 | 菜单栏持续区分未连接、查找中、USB、蓝牙配置通道与当前配置档；菜单栏“进入设置”、Dock 点击和应用重新激活均恢复或显示同一个主窗口，不产生重复窗口 |
| FR-02 | 主窗口导航 | 提供状态总览、配置档、动作库、设备与同步、权限；侧栏底部提供设置和关于 |
| FR-03 | 管理配置档 | 可显示、选择、编辑和新建本地配置档；选择或编辑不自动同步 |
| FR-04 | 编辑 11 个控制事件 | KEY1-KEY8、旋钮左转、按下、右转均可设为本机动作、固定文本、键盘组合键或禁用；控制面使用 `4 x 2` 宏键盘和旋钮的固定布局 |
| FR-05 | 维护动作库 | 独立页面登记、筛选、测试和删除应用、网址、快捷指令、系统动作；同时维护固定文本与键盘组合键预设；不显示 UUID、绝对路径或安全书签 |
| FR-06 | 读取并登记本机应用 | 扫描用户、系统和本地“应用程序”目录中的 `.app`；列表只显示名称、图标和来源，选中后才保存该应用的安全书签；已登记应用在列表和按键映射中显示运行时解析的图标 |
| FR-06a | 维护输入预设 | 固定文本和键盘组合键预设可新建、编辑、删除与选择；映射到控制件时复制当前值，编辑预设不改写已有控制件或已同步配置 |
| FR-06b | 录制组合键 | 用户显式进入录制后按下组合键，应用将支持的按键规范化为固件现有格式；仅修饰键和不支持的按键不保存并提示原因 |
| FR-07 | 提供可配置的直接工具 | 可登记“打开系统截图与录屏界面、锁定屏幕、仅防止闲置显示器休眠、设置用户选定壁纸、音量增减/静音、隐藏前台应用、Apple Music 播放/暂停/上一首/下一首”等动作；均仍须映射到控制件才会由设备触发 |
| FR-08 | 提供快捷指令模板 | 深色模式、屏保、键盘清洁、隐藏桌面文件、隐藏 Dock、分屏布局、显示器亮度和键盘亮度只创建快捷指令登记入口；用户必须先在“快捷指令”中创建并授权实际动作 |
| FR-09 | 限制手动测试 | 仅已登记本机动作可由应用测试；固定文本和组合键提示实体设备验证；锁屏测试需二次确认 |
| FR-10 | 生成设备配置 | 输出 `ai_keyboard.v1` JSON，包含 8 键和单枚旋钮三个事件的完整字段 |
| FR-11 | 配置同步 | USB 可写时优先 USB；仅 USB 不存在时才使用蓝牙配置通道；USB 失败不回退 |
| FR-12 | 只在确认后显示成功 | 回执必须满足 phase=1、ok=true、saved=true、bytes/CRC 匹配；保存同步确认历史 |
| FR-13 | 展示设备与同步事实 | 展示连接、当前配置、上次确认时间与回执摘要；固件、备用通道、能力未读取时显示“未读取” |
| FR-14 | 执行与记录本机动作 | 仅对规范小写 UUID 查找本地登记项；记录设备 Host Action 与手动测试的可确认结果 |
| FR-15 | 处理权限 | 辅助功能可由用户明确发起系统授权请求并在重新激活时复查；自动化仅在首次相关执行后依据实际结果显示状态，不伪造全局授权结果 |
| FR-16 | 偏好和关于 | 菜单栏显示默认开启、开机启动默认关闭；开机启动仅在用户启用时请求系统登录项服务。关于页显示包内版本和构建信息 |

## 3. 主要场景

### 3.1 配置并同步一个本机动作

用户在“动作库”中登记一个应用，或在配置档中从动作库选择已有动作。动作库可读取常规应用程序目录，用户在列表中选中一个应用后，EasyMacBord 才将 UUID 与该应用的安全书签保存在本机；设备配置中只写入 `host_action:<uuid>`。应用图标由安全书签解析后的目标在运行时取得，不持久化为设备数据。同步仅在设备确认同一份内容已经保存后结束。

### 3.1a 配置文本或组合键

用户在动作库维护固定文本或组合键预设。组合键在录制控件获得焦点后由实际按键生成规范格式，不要求用户手写修饰符字符串。用户将预设应用到某个按键或旋钮事件时，当前标题和值复制到该控制件的 `ActionBinding`；设备仍接收现有文本或组合键字段，不新增 UUID、固件类型或协议字段。预设后续变更只影响下一次选择，不回写已保存或已同步的控制件。

### 3.2 手动测试与实体设备验证

用户可以在检查器测试已登记的应用、网址、快捷指令或系统动作。固定文本和键盘组合键不能由应用确认其在目标上下文中生效，因此界面只提示通过实体设备验证。锁定屏幕等会影响当前会话的系统动作须在确认弹窗中再次确认。打开系统截图与录屏界面只证明系统界面已被请求打开，不证明截图或录屏文件已生成。

### 3.3 选择工具类型

用户可将直接工具登记为本机动作：打开系统截图与录屏界面、锁定屏幕、保持屏幕唤醒、壁纸、音量、隐藏前台应用和 Apple Music 基础控制。其中“保持屏幕唤醒”只防止闲置显示器休眠，不保证合盖时继续运行，也不替代锁屏策略。壁纸必须由用户通过选择面板选图；Apple Music 控制由系统自动化权限约束。

深色模式、屏保、键盘清洁、隐藏桌面文件、隐藏 Dock、分屏布局、显示器亮度、键盘亮度不提供内置绕过实现。动作库只提供预填标题的快捷指令登记，实际快捷指令名称、内容和授权由用户维护。

### 3.4 同步失败后查看历史

当写入失败、超时或回执不匹配时，页面显示本次失败原因；上一次已确认时间和回执摘要仍可见。失败不标记本次配置已保存，也不覆盖历史确认记录。

### 3.5 权限不足

辅助功能由用户在权限页明确发起系统授权请求；应用重新激活或用户点击重新检查时复查状态。Apple Music 和快捷指令等自动化动作在首次执行后依据系统结果显示已授权、调用失败或待检查；只有系统明确给出授权提示时，才提示用户在系统设置中确认。当前截图与录屏动作只打开系统截图面板，不申请或检查屏幕录制权限。

## 4. 约束与非功能要求

- **平台：** 最低 macOS 26，`arm64`；不支持 Intel。
- **窗口与界面：** 默认 `1280 x 800`，最小 `1120 x 720`。使用系统导航、工具栏、材料与 SF Symbols；玻璃效果只用于少量高优先级摘要，不作为信息载体。
- **数据边界：** 设备端只保存动作 UUID；本机路径以安全书签保存。用户主动创建的固定文本和组合键预设、以及对应控制件值必须保存在本机配置中，才可同步到设备；它们不写入常规日志、动作记录、截图证据或诊断输出。界面不显示 UUID、路径或安全书签。
- **应用目录：** 应用目录扫描只读取常规应用程序目录并在内存中保留候选位置；未被用户选中的应用不写入动作库。列表不显示绝对路径。
- **系统动作：** 不写入 Finder、Dock 或显示器私有偏好，不调用私有显示器接口；系统无法提供稳定通用接口的能力统一通过用户自己的快捷指令接入。
- **输入预设：** 文本与组合键预设仅是 Mac 本地编辑便利功能；控制件保存的是当时复制的值，现有设备序列化格式不改变。
- **窗口与偏好：** Dock 始终可用于恢复窗口，即使用户关闭菜单栏显示。菜单栏默认开启；开机启动默认关闭且只在用户明确切换后调用系统服务。
- **可靠性：** 配置不以“已发送”判定成功；非法协议 fail closed；双通道不重复执行；本次同步失败不覆盖上次确认。
- **可访问性：** 关键按钮有文字或可读名称；长名称截断并支持完整值提示；状态不只依赖颜色。

## 5. 失败处理

| 情况 | 界面反馈 | 系统行为 |
|---|---|---|
| 无设备 | “未建立可写入通道” | 不发送配置 |
| USB 写入失败 | “USB 写入失败” | 不自动改走蓝牙配置通道 |
| 回执长度或 CRC 不一致 | “设备未确认保存” | 保留上次确认记录，不将本次标记成功 |
| 状态读取协议不存在 | “未读取” | 不推断固件、备用通道或设备能力 |
| UUID 非规范格式 | “设备消息格式无效” | 不查询映射、不执行 |
| 本机动作未登记 | “本机动作未登记” | 不执行；记录失败类别 |
| 目标应用已移动 | “应用位置已变更，请重新选择” | 不启动替代目标；图标回退为通用应用图标 |
| 应用目录未发现候选项 | “没有找到应用” | 不登记未确认的路径；用户可返回并改用手动选择 |
| 音频输出不支持音量控制 | “当前音频输出不支持音量控制” | 不修改其他输出设备 |
| Apple Music 不可用或自动化被拒绝 | 显示 Apple Music 自动化失败 | 不改用其他音乐应用，不报告播放成功 |
| 快捷指令不存在或执行失败 | 显示快捷指令执行失败 | 不猜测或创建同名快捷指令 |
| 组合键只包含修饰键或不受支持按键 | 显示“无法记录此组合键” | 不更新预设或控制件值 |
| 开机启动需要系统确认 | 显示“需要在登录项中确认” | 不宣称已启用；保留系统返回状态 |

## 6. 明确不包含

- AI 对话、总结、翻译、TTS、语音输入、板端录音和 Wi-Fi 音频。
- 音乐律动、外接显示器 DDC、自动更新、远程账户同步。
- 修改 Maker 固件、烧录、改变 GPIO、BOOT、GPIO8 电源、分区、HID/GATT 描述符或设备身份。
- 深色模式、屏保、键盘清洁、隐藏桌面文件、隐藏 Dock、分屏、显示器亮度与键盘亮度的内置私有实现；这些仅可接入用户自行设置的快捷指令。
- 应用内屏幕采集或录制。当前“截图与录屏”动作只打开 macOS 截图面板。
- 本期新增固件状态读取协议、设备能力探测或移动端布局。

## 7. 发布要求

应用使用 ad-hoc 签名，TeamIdentifier 为空；不使用 Developer ID，不公证。发布包为 DMG，并在发布说明中写明 Gatekeeper 的手动放行限制。
