# EasyMacBord 软件需求规格说明书

**版本：** v0.1 UI 改造
**目标读者：** 产品负责人、macOS 开发人员、EasyInput 固件维护人员和真机测试人员

## 1. 背景与目标

EasyInput V2.0 可通过 USB HID 发送实体输入，并提供蓝牙配置通道写入配置；设备也可发送 Host Action UUID。用户需要在 Mac 上维护多个配置档，并把“打开应用”等本机动作绑定到实体控制件。设备不应持有应用路径、应用名称或启动参数。

本次改造的目标是把现有功能整理为清晰的四页配置工具：用户可查看真实连接与同步状态，编辑 8 个按键和单枚旋钮的三个事件，在配置页内登记本机动作，并在收到合法 UUID 时执行已登记动作。设备未上报的数据不作推断。

## 2. 功能需求

| 编号 | 需求 | 验收条件 |
|---|---|---|
| FR-01 | 菜单栏显示设备状态和当前配置档 | 未连接、查找中、USB、蓝牙配置通道状态可区分 |
| FR-02 | 主窗口提供四项导航 | 仅有状态总览、配置档、设备与同步、权限；无独立本机动作页 |
| FR-03 | 管理配置档 | 可显示、选择、编辑和新建本地配置档；选择或编辑不自动同步 |
| FR-04 | 编辑 11 个控制事件 | KEY1-KEY8、旋钮左转、按下、右转均可设为本机动作、固定文本、键盘组合键或禁用 |
| FR-05 | 在检查器管理本机动作 | 可登记和选择应用、网址、快捷指令、系统动作；不显示 UUID、绝对路径或安全书签 |
| FR-06 | 限制手动测试 | 仅已登记本机动作可由应用测试；固定文本和组合键提示实体设备验证；锁屏测试需二次确认 |
| FR-07 | 生成设备配置 | 输出 `ai_keyboard.v1` JSON，包含 8 键和单枚旋钮三个事件的完整字段 |
| FR-08 | 配置同步 | USB 可写时优先 USB；仅 USB 不存在时才使用蓝牙配置通道；USB 失败不回退 |
| FR-09 | 只在确认后显示成功 | 回执必须满足 phase=1、ok=true、saved=true、bytes/CRC 匹配；保存同步确认历史 |
| FR-10 | 展示设备与同步事实 | 展示连接、当前配置、上次确认时间与回执摘要；固件、备用通道、能力未读取时显示“未读取” |
| FR-11 | 执行与记录本机动作 | 仅对规范小写 UUID 查找本地登记项；记录设备 Host Action 与手动测试的可确认结果 |
| FR-12 | 处理权限 | 展示辅助功能、屏幕录制、自动化的当前状态或按需检查状态 |

## 3. 主要场景

### 3.1 配置并同步一个本机动作

用户在“配置档”中选择 KEY1，选择“本机动作”，并在右侧检查器登记一个目标应用。EasyMacBord 将 UUID 与应用安全书签保存在本机，在设备配置中写入 `host_action:<uuid>`。同步仅在设备确认同一份内容已经保存后结束。

### 3.2 手动测试与实体设备验证

用户可以在检查器测试已登记的应用、网址、快捷指令或非破坏性系统动作。固定文本和键盘组合键不能由应用确认其在目标上下文中生效，因此界面只提示通过实体设备验证。锁定屏幕等会影响当前会话的系统动作须在确认弹窗中再次确认。

### 3.3 同步失败后查看历史

当写入失败、超时或回执不匹配时，页面显示本次失败原因；上一次已确认时间和回执摘要仍可见。失败不标记本次配置已保存，也不覆盖历史确认记录。

### 3.4 权限不足

若动作需要辅助功能或屏幕录制，界面显示“需要授权”，不伪造成功。用户完成系统授权后可重新检查并重试该动作。

## 4. 约束与非功能要求

- **平台：** 最低 macOS 26，`arm64`；不支持 Intel。
- **窗口与界面：** 默认 `1280 x 800`，最小 `1120 x 720`。使用系统导航、工具栏、材料与 SF Symbols；玻璃效果只用于少量高优先级摘要，不作为信息载体。
- **数据边界：** 设备端只保存动作 UUID；本机路径以安全书签保存；常规日志、动作记录和界面不记录 UUID、路径、用户文本或设备唯一标识。
- **可靠性：** 配置不以“已发送”判定成功；非法协议 fail closed；双通道不重复执行；本次同步失败不覆盖上次确认。
- **可访问性：** 关键按钮有文字或可读名称；长名称截断并支持完整值提示；状态不只依赖颜色。

## 5. 失败处理

| 情况 | 界面反馈 | 系统行为 |
|---|---|---|
| 无设备 | “未建立可写入通道” | 不发送配置 |
| USB 写入失败 | “USB 写入失败” | 不自动改走蓝牙配置通道 |
| 回执长度或 CRC 不一致 | “设备未确认保存” | 保留上次确认记录，不将本次标记成功 |
| 状态读取协议不存在 | “未读取” | 不推断固件、备用通道或设备能力 |
| UUID 非规范格式 | “设备消息格式无效” | 不查询映射、不执行 |
| 本机动作未登记 | “本机动作未登记” | 不执行；记录失败类别 |
| 目标应用已移动 | “应用位置已变更，请重新选择” | 不启动替代目标 |

## 6. 明确不包含

- AI 对话、总结、翻译、TTS、板端录音和 Wi-Fi 音频。
- 音乐律动、外接显示器 DDC、自动更新、远程账户同步。
- 修改 Maker 固件、烧录、改变 GPIO、BOOT、GPIO8 电源、分区、HID/GATT 描述符或设备身份。
- 未经用户设置的应用启动、自动化或屏幕录制。
- 本期新增固件状态读取协议、设备能力探测或移动端布局。
