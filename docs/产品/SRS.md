# EasyMacBord 软件需求规格说明书

**版本：** v0.1 UI 改造、T03 可配置工具与本机应用（已实现，待人工验收）、T04 桌面体验与动作中心（已实现，待完整 UI 与实物验收）、T05 动作与场景（已实现，待系统与实物验收）
**目标读者：** 产品负责人、macOS 开发人员、EasyInput 固件维护人员和真机测试人员

## 1. 背景与目标

EasyInput V2.0 可通过 USB HID 发送实体输入，并提供蓝牙配置通道写入配置；设备也可发送 Host Action UUID。用户需要在 Mac 上维护多个配置档，并把“打开应用”等本机动作绑定到实体控制件。设备不应持有应用路径、应用名称或启动参数。

本次改造的目标是提供可恢复的主窗口和清晰的动作维护入口：用户可查看真实连接与同步状态，编辑 8 个按键和单枚旋钮的三个事件，在独立动作库登记本机动作或维护文本、组合键预设，并在收到合法 UUID 时执行已登记的 Host Action。T05 在现有配置档上增加前台应用自动切换规则、状态读取与设备语义动作门控；设备未上报的数据不作推断。

| FR-02 | 主窗口导航 | 提供状态总览、配置档、动作库、设备与同步、权限；侧栏底部提供设置和关于 |
| FR-03 | 管理配置档 | 可显示、选择、编辑和新建本地配置档；选择或编辑不自动同步 |
| FR-04 | 编辑 11 个控制事件 | KEY1-KEY8、旋钮左转、按下、右转均可设为本机动作、设备语义动作、固定文本、键盘组合键或禁用；控制面使用 `4 x 2` 宏键盘和旋钮的固定布局 |

| FR-09 | 限制手动测试 | 仅已登记本机动作可由应用测试；固定文本和组合键提示实体设备验证；锁屏测试需二次确认 |
| FR-10 | 生成设备配置 | 输出 `ai_keyboard.v1` JSON，包含 8 键和单枚旋钮三个事件的完整字段 |
| FR-11 | 配置同步 | USB 可写时优先 USB；仅 USB 不存在时才使用蓝牙配置通道；USB 失败不回退 |
| FR-12 | 只在确认后显示成功 | 回执必须满足 phase=1、ok=true、saved=true、bytes/CRC 匹配，且来源与本次发送通道一致；保存同步确认历史 |

| FR-15 | 处理权限 | 辅助功能可由用户明确发起系统授权请求并在重新激活时复查；自动化仅在首次相关执行后依据实际结果显示状态；通知只在喝水提醒实际执行并取得系统结果后更新，不伪造全局授权结果 |
| FR-16 | 偏好和关于 | 菜单栏显示默认开启、开机启动默认关闭；开机启动仅在用户启用时请求系统登录项服务。关于页显示包内版本和构建信息 |
| FR-17 | 读取设备状态 | USB 已连接时可通过按钮以既有 `0x13 / S3R v1` Feature Report 请求状态，接受与请求 ID 匹配的 `0x11 / kind 0x04` 分片响应；只有协议版本、分片、长度和 CRC 全部匹配时才解析 `ai_keyboard.config_status.v1` |
| FR-18 | 管理前台应用规则 | 为配置档添加、启停和移除基于应用 Bundle ID 的自动切换规则；不保存应用路径或安全书签，同一应用不得存在多条启用规则 |
| FR-19 | 使用设备语义动作 | 只有已校验状态 JSON 的 `capabilities.semantic_actions=true` 时才提供 `select_all`、`copy`、`paste`、`undo` 等既有设备动作；`voice_ptt_hold` 与 `edit_ptt_hold` 分别要求已读取对应 PTT 字段，否则显示“设备未确认” |
| FR-20 | 自动同步前台应用切换 | 匹配规则后先选择对应配置档；设备已连接、本地保存完成且不在同步中时，等待 750 ms 再同步当前配置。手动同步取消等待，不与自动同步并发 |
| FR-21 | 确认清空废纸篓 | “清空废纸篓”动作必须在当前 Mac 显示确认框；取消不执行，确认后才请求 Finder 清空废纸篓 |
| FR-22 | 提供手动更新检查 | 关于页读取公开 GitHub Releases；正式包忽略预发布，Beta 包包含预发布。只展示 Release 信息、`arm64` DMG 和对应 SHA-256 外部链接；不下载、安装、替换或自动启动 ad-hoc 新版本 |
| FR-23 | 提供喝水提醒 | 可创建 1 至 1440 分钟的提醒动作，默认 30 分钟；实际执行时才请求通知并更新通知状态 |
| FR-24 | 提供清洁屏幕遮罩 | 触发后显示可由“关闭”或 Escape 退出的黑色遮罩；不读取屏幕内容或禁止物理键盘输入 |

## 3. 主要场景

### 3.1 配置并同步一个本机动作

用户在“动作库”中登记一个应用，或在配置档中从动作库选择已有动作。动作库可读取常规应用程序目录，用户在列表中选中一个应用后，EasyMacBord 才将 UUID 与该应用的安全书签保存在本机；设备配置中只写入 `host_action:<uuid>`。应用图标由安全书签解析后的目标在运行时取得，不持久化为设备数据。同步仅在设备确认同一份内容已经保存后结束。

### 3.1a 配置文本或组合键

用户在动作库维护固定文本或组合键预设。除录制控件外，动作库提供剪切 `Meta+X`、删除 `Backspace`、回车 `Return`、聚焦搜索 `Meta+Space`、切换输入法 `Ctrl+Space` 五个内建组合键预设。用户将预设应用到某个按键或旋钮事件时，当前标题和值复制到该控制件的 `ActionBinding`；预设后续变更只影响下一次选择，不回写已保存或已同步的控制件。

### 3.2 手动测试与实体设备验证

用户可以在检查器测试已登记的应用、网址、快捷指令或系统动作。固定文本和键盘组合键不能由应用确认其在目标上下文中生效，因此界面只提示通过实体设备验证。锁定屏幕等会影响当前会话的系统动作须在确认弹窗中再次确认。打开系统截图与录屏界面只证明系统界面已被请求打开，不证明截图或录屏文件已生成。

### 3.3 选择工具类型

用户可将直接工具登记为本机动作：打开系统截图与录屏界面、锁定屏幕、保持屏幕唤醒、壁纸、音量、隐藏前台应用、Apple Music 基础控制、打开终端、清洁屏幕遮罩、喝水提醒、清空废纸篓和整理桌面。其中“保持屏幕唤醒”只防止闲置显示器休眠，不保证合盖时继续运行，也不替代锁屏策略。壁纸必须由用户通过选择面板选图；Apple Music 控制由系统自动化权限约束。

喝水提醒登记时的间隔范围是 1 至 1440 分钟，表单默认 30 分钟。登记动作本身不请求通知，也不更新权限页；只有动作实际执行时才按系统结果显示通知已授权或调用失败。清洁屏幕遮罩只是可关闭的黑色覆盖层，不尝试锁定物理键盘。清空废纸篓必须经本机确认，确认才请求 Finder 执行。

深色模式、屏保、键盘清洁、隐藏桌面文件、隐藏 Dock、分屏布局、显示器亮度、键盘亮度不提供内置绕过实现。动作库只提供预填标题的快捷指令登记，实际快捷指令名称、内容和授权由用户维护。

### 3.4 同步失败后查看历史

当写入失败、超时或回执不匹配时，页面显示本次失败原因；上一次已确认时间和回执摘要仍可见。失败不标记本次配置已保存，也不覆盖历史确认记录。

### 3.5 权限不足

辅助功能由用户在权限页明确发起系统授权请求；应用重新激活或用户点击重新检查时复查状态。Apple Music 和快捷指令等自动化动作在首次执行后依据系统结果显示已授权、调用失败或待检查；喝水提醒也只在实际执行时请求通知并更新状态。当前截图与录屏动作只打开系统截图面板，不申请或检查屏幕录制权限。

### 3.6 前台应用切换配置档与读取设备状态

用户在当前配置档的“自动切换”界面选择一个带 Bundle ID 的本机应用，并可启停或移除规则。该应用变为前台时，应用先选中对应配置档；设备已连接、本地保存完成且没有同步进行时，再等待 750 ms 同步当前配置。未连接或仍在写入时不发送配置。用户在“设备与同步”点击“读取设备状态”后，只有重组后的 `0x04` 状态 JSON 与请求 ID、长度和 CRC 匹配时，才更新固件、能力和 PTT 热键字段。

### 3.7 设备语义动作与手动同步

`semantic_actions=true` 时，映射检查器可显示 Maker 已有的设备语义动作；`voice_ptt_hold` 与 `edit_ptt_hold` 分别要求对应 PTT 热键字段已读取。语义动作直接写入既有设备配置，不走 Host Action UUID，也不调用 Mac 本机动作。用户点击“同步当前配置”会取消等待中的自动同步并发送当前版本一次。同步仍须收到同一发送通道的保存确认且 bytes 和 CRC 匹配，失败不跨 USB/BLE 通道重试。

### 3.8 本机破坏性操作与更新

移除本地动作、预设或自动切换规则只影响 EasyMacBord 本地登记。清空系统废纸篓是不同操作：触发后必须在本机确认，确认才请求 Finder 执行，取消不执行。用户在关于页点击“检查更新”时，应用读取公开 GitHub Releases；正式包忽略预发布，Beta 包包含预发布。应用只展示可用 Release 的信息、`arm64` DMG 和对应 SHA-256 外部链接，用户在默认浏览器中自行完成下载、替换和 Gatekeeper 放行。

## 4. 约束与非功能要求

- **平台：** 最低 macOS 26，`arm64`；不支持 Intel。
- **窗口与界面：** 默认 `1280 x 800`，最小 `1120 x 720`。使用系统导航、工具栏、材料与 SF Symbols；玻璃效果只用于少量高优先级摘要，不作为信息载体。
- **数据边界：** Host Action 的设备端引用为 UUID；设备语义动作保存 Maker 已有的原始动作值。本机路径以安全书签保存。用户主动创建的固定文本和组合键预设、以及对应控制件值必须保存在本机配置中，才可同步到设备；它们不写入常规日志、动作记录、截图证据或诊断输出。界面不显示 UUID、路径或安全书签。
- **更新检查数据：** 更新检查只访问公开 GitHub Releases API，不要求 GitHub 登录或访问令牌；Release 列表、说明和下载链接只用于本次界面显示，不写入配置、诊断记录或截图证据。
- **应用目录：** 应用目录扫描只读取常规应用程序目录并在内存中保留候选位置；未被用户选中的应用不写入动作库。列表不显示绝对路径。
- **自动切换规则：** 规则只保存配置档 ID、应用 Bundle ID、显示名和启用状态；不保存路径或安全书签。前台应用事件没有有效规则、自动切换关闭、配置档未保存或设备未连接时不得发起同步。
- **系统动作：** 不写入 Finder、Dock 或显示器私有偏好，不调用私有显示器接口；系统无法提供稳定通用接口的能力统一通过用户自己的快捷指令接入。
- **输入预设：** 文本与组合键预设仅是 Mac 本地编辑便利功能；控制件保存的是当时复制的值，现有设备序列化格式不改变。
- **窗口与偏好：** Dock 始终可用于恢复窗口，即使用户关闭菜单栏显示。菜单栏默认开启；开机启动默认关闭且只在用户明确切换后调用系统服务。
- **状态读取：** Status HID v1 使用既有 Report ID `0x13` 和 `0x11 / kind 0x04` 容器；读取按钮只在 USB 已连接时可用。状态读取与保存确认、Host Action 分流处理。校验失败的状态不得更新能力或覆盖已校验快照。
- **自动切换与同步：** 前台应用规则匹配后固定 750 ms 防抖，只发送当前已保存的配置档版本；USB 优先、失败不回退和确认匹配约束保持不变。
- **通知与破坏性操作：** 喝水提醒的通知状态仅由实际执行结果更新；清空废纸篓必须在本机确认。更新检查只读取公开 Release 列表并提供外部链接，不构成自动更新能力。
- **可靠性：** 配置不以“已发送”判定成功；非法协议 fail closed；回执必须关联本次发送通道；本次同步失败不覆盖上次确认。
- **可访问性：** 关键按钮有文字或可读名称；长名称截断并支持完整值提示；状态不只依赖颜色。

## 5. 失败处理

| 情况 | 界面反馈 | 系统行为 |
|---|---|---|
| 无设备 | “未建立可写入通道” | 不发送配置 |
| USB 写入失败 | “USB 写入失败” | 不自动改走蓝牙配置通道 |
| 回执长度或 CRC 不一致 | “设备未确认保存” | 保留上次确认记录，不将本次标记成功 |
| 状态读取协议不存在 | “未读取” | 不推断固件、备用通道或设备能力 |
| UUID 非规范格式 | “设备消息格式无效” | 不查询映射、不执行 |
| 本机动作未登记 | “本机动作未登记” | 不执行；记录失败类别 |
| 目标应用已移动 | “应用位置已变更，请重新选择” | 不启动替代目标；图标回退为通用应用图标 |
| 应用目录未发现候选项 | “没有找到应用” | 不登记未确认的路径；用户可返回并改用手动选择 |
| 音频输出不支持音量控制 | “当前音频输出不支持音量控制” | 不修改其他输出设备 |
| Apple Music 不可用或自动化被拒绝 | 显示 Apple Music 自动化失败 | 不改用其他音乐应用，不报告播放成功 |
| 快捷指令不存在或执行失败 | 显示快捷指令执行失败 | 不猜测或创建同名快捷指令 |
| 组合键只包含修饰键或不受支持按键 | 显示“无法记录此组合键” | 不更新预设或控制件值 |
| 开机启动需要系统确认 | 显示“需要在登录项中确认” | 不宣称已启用；保留系统返回状态 |
| 状态分片不完整、请求 ID 不符、长度或 CRC 不符 | “设备状态未确认” | 丢弃本次状态，保留上次已校验快照，不更新能力判断 |
| 语义动作能力缺失或为 false | “设备未确认” | 普通配置档和既有 Host Action 仍可使用；不提供设备语义动作映射 |
| PTT 热键字段未读取 | “设备未确认” | 不提供语音或编辑按住说话映射 |
| 灯光或音乐律动 | “需要设备合同” | 不显示可操作开关，不发送推测命令 |
| 前台应用自动切换期间发生新匹配 | “等待同步” | 重置 750 ms 防抖，只保留当前选中且已保存的配置档待发送 |
| 自动同步失败 | “同步失败，保留本地更改” | 停止本次发送，不跨通道重试；用户可手动重试 |
| 清空废纸篓 | “确认清空废纸篓” | 取消不执行；确认后才请求 Finder 清空系统废纸篓 |
| 喝水提醒通知未授权或安排失败 | “未获通知权限”或“无法安排喝水提醒” | 仅在动作实际执行后将通知状态标为调用失败 |
| 检查更新 | “正在检查公开 Release” | 只显示可用 Release、`arm64` DMG 和 SHA-256 外部链接；在浏览器中由用户下载，不替换当前应用 |

## 6. 明确不包含

- AI 对话、总结、翻译、TTS、语音输入、板端录音和 Wi-Fi 音频。
- 灯光控制、音乐律动、外接显示器 DDC、自动更新、远程账户同步。
- 修改 Maker 固件、烧录、改变 GPIO、BOOT、GPIO8 电源、分区、HID/GATT 描述符或设备身份。
- 深色模式、屏保、键盘清洁、隐藏桌面文件、隐藏 Dock、分屏、显示器亮度与键盘亮度的内置私有实现；这些仅可接入用户自行设置的快捷指令。
- 应用内屏幕采集或录制。当前“截图与录屏”动作只打开 macOS 截图面板。
- 本期新增固件状态读取协议、设备能力探测或移动端布局。
- 灯光或律动的新设备控制合同。现有状态读取只消费 Maker 已有 `ai_keyboard.config_status.v1`，不扩展设备字段或命令。
