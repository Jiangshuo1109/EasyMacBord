# 测试计划

## 证据层级

| 层级 | 证明什么 | 不能证明什么 |
|---|---|---|
| 单元测试 | 编码、路由、确认和本地数据逻辑 | 设备实际收发 |
| 应用构建 | arm64 应用可被工具链编译 | 签名、真机功能 |
| 配置确认 | 设备保存了同一份 JSON | 物理按键和本机动作 |
| 真机验收 | 实体输入的实际结果 | 以后版本持续兼容 |

## 自动化测试

1. CRC 向量、1/52/53/2048/2049 字节边界、分片头和 CRC。
2. `0x03` 确认的成功、错误分片头、saved=false、bytes 不同、CRC 不同，以及 8 秒无确认超时。
3. `0x05` 的小写 UUID、大小写错误、长度错误、前缀错误；`0x04` 不执行动作。
4. KEY1-KEY8 与旋钮的完整 JSON 序列化，固定文本、热键、Host Action 与禁用状态。
5. USB 优先、USB 失败不回退、USB 缺失时蓝牙配置通道可用；HID 输入的 USB 优先、BLE-only 回退，以及 macOS `Bluetooth Low Energy` 传输名归一化。
6. ProfileStore 版本化读写、v0 裸数组迁移、初始配置和新建配置档；Host Action 的登记、恢复和缺失映射失败。
7. 配置档、动作库和同步历史的写入版本：晚到的旧快照不得覆盖最新编辑。
8. 同步历史：有效确认写入时间与回执摘要、失败不覆盖最后一次有效确认、历史读取失败的降级提示。
9. 手动测试记录：已登记动作的成功与失败记录、未登记动作不执行、固定文本和键盘组合键不产生“已执行”记录。
10. 未知设备信息：固件版本、备用通道、能力在未收到状态协议数据时均为“未读取”。
11. 蓝牙配置通道多分片逐帧回调后发送、写入失败和中断。该项依赖可注入的 CoreBluetooth 适配器，当前仅保留真机前的实现检查。
12. 应用目录扫描：顶层与嵌套 `.app` 发现、显示名称回退、同 Bundle ID 去重、无 Bundle ID 候选项区分和扫描目录优先顺序。测试使用临时目录，不读取用户真实应用程序目录。
13. 工具登记：直接系统工具标识唯一且稳定；快捷指令模板名称与产品规格一致。不得以自动化测试实际锁屏、改壁纸、改音量或控制 Music。

## UI 检查

在 `1280 x 800` 与 `1120 x 720` 分别截图检查四页。窗口小于最小尺寸不作为适配目标。

Debug 构建可使用 `--ui-state <名称>` 载入固定截图状态：`disconnected`、`connecting`、`sync-sending`、`sync-confirmed`、`sync-failed`、`empty-actions`、`permission-denied`、`long-names`。该入口不编入 Release 产物，不连接设备、不读取用户本地数据。

- 状态总览：未连接、连接中、USB、蓝牙配置通道、同步中、同步失败、同步确认、无本机动作记录与长名称截断。
- 配置档：顶部配置档选择器、新建配置档、KEY1-KEY8、单旋钮左转/按下/右转、四种动作类型、无已登记动作、登记后选择动作、测试边界与锁屏二次确认。
- 设备与同步：当前连接、上次确认与本次失败同时出现、回执摘要、固件版本/备用通道/能力“未读取”。
- 权限：已授权、拒绝、按需检查和重新检查后的文本与图标状态。
- 全局：四项导航无“本机动作”独立入口；不展示 UUID、绝对路径、安全书签或虚构的设备详情；标题、按键卡片、检查器和底部操作区不重叠。
- 动作库：从本机应用登记时可搜索、刷新和选择应用；只出现名称、图标与来源，不出现绝对路径。直接工具与快捷指令模板都需先登记再可映射到控制件。
- T03 工具状态：无可用音频输出、Apple Music 自动化被拒绝、快捷指令执行失败、无匹配应用和已选应用失效均需显示或保留可操作的边界，不能改为其他目标或显示“已执行”。

## T03 人工验收

以下项目尚待执行。操作会影响系统状态时，应在测试后恢复原状态，并在记录中只写动作名称、结果和失败层，不记录用户路径、设备唯一标识或原始日志。

| 编号 | 场景 | 通过条件 | 证据边界 |
|---|---|---|---|
| M-01 | 本机应用目录 | 能发现用户、本地或系统应用目录中的可用 `.app`，选择后才可登记为动作 | 不记录完整应用路径；未选择项不持久化 |
| M-02 | 已登记应用 | 测试动作实际启动用户选择的测试应用 | 仅证明应用启动，不替代设备按键验证 |
| M-03 | 截图与录屏 | 测试动作打开系统截图界面 | 不以此证明截图或录屏文件已经生成 |
| M-04 | 保持唤醒 | 启用后在闲置期间不触发显示器闲置休眠；关闭后释放该状态 | 不测试合盖、强制睡眠或系统锁屏规避 |
| M-05 | 壁纸 | 仅在用户选图后更换桌面背景，测试结束可恢复原背景 | 不访问或扫描照片库 |
| M-06 | 音量与隐藏应用 | 默认输出支持时音量增减/静音生效；隐藏操作只隐藏当前前台应用 | 不支持的输出要明确失败；不终止应用 |
| M-07 | Apple Music | 在已授权自动化且 Music 可用时，基础控制命令被 Music 接收 | 不以命令提交推断实际扬声器播放；不测试其他播放器 |
| M-08 | 快捷指令模板 | 用户创建并授权对应快捷指令后，登记名称可调用正确快捷指令 | 深色模式、屏保、键盘清洁、隐藏桌面文件/Dock、分屏、显示器/键盘亮度均由用户快捷指令负责 |

## 真机矩阵

只有收到同一份配置的保存确认后才可开始。每项单独记录条件、用户观察、时间、结果和失败层。

| 编号 | 项目 | 通过条件 |
|---|---|---|
| HW-01 | USB-only | 配置确认成功，按键触发目标动作 |
| HW-02 | 仅 BLE（HID 输入与配置通道） | 配置确认成功，按键触发目标动作 |
| HW-03 | 双连接 | 同一按键只执行一次 |
| HW-04 | 按下 | 单次按下只产生一次动作 |
| HW-05 | 松开 | 松开不重复触发 |
| HW-06 | 回归 | 复制、粘贴、快捷键、固定文本仍正常 |
| HW-07 | 本机应用 | 已选目标应用实际打开 |

任一项目未执行即为 `UNKNOWN`，不能用其余项目替代。

T03 的 M-01 至 M-08 是 Mac 本地动作验证；它们不替代 HW-01 至 HW-07 的设备同步、输入和单发矩阵。固件、HID/GATT 描述符和 S3C v1 协议在本阶段不变。
