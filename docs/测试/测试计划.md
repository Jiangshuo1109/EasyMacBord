# 测试计划

## 证据层级

| 层级 | 证明什么 | 不能证明什么 |
|---|---|---|
| 单元测试 | 编码、路由、确认和本地数据逻辑 | 设备实际收发 |
| 应用构建 | arm64 应用可被工具链编译 | 签名、真机功能 |
| 配置确认 | 设备保存了同一份 JSON | 物理按键和本机动作 |
| 真机验收 | 实体输入的实际结果 | 以后版本持续兼容 |

## 自动化测试

1. CRC 向量、1/52/53/2048/2049 字节边界、分片头和 CRC。
2. `0x03` 确认的成功、错误分片头、saved=false、bytes 不同、CRC 不同，以及 8 秒无确认超时。
3. `0x05` 的小写 UUID、大小写错误、长度错误、前缀错误；`0x04` 不执行动作。
4. KEY1-KEY8 与旋钮的完整 JSON 序列化，固定文本、热键、Host Action 与禁用状态。
5. USB 优先、USB 失败不回退、USB 缺失时蓝牙配置通道可用；HID 输入的 USB 优先、BLE-only 回退，以及 macOS `Bluetooth Low Energy` 传输名归一化。
6. ProfileStore 版本化读写、v0 裸数组迁移、初始配置和新建配置档；Host Action 的登记、恢复和缺失映射失败。
7. 配置档、动作库和同步历史的写入版本：晚到的旧快照不得覆盖最新编辑。
8. 同步历史：有效确认写入时间与回执摘要、失败不覆盖最后一次有效确认、历史读取失败的降级提示。
9. 手动测试记录：已登记动作的成功与失败记录、未登记动作不执行、固定文本和键盘组合键不产生“已执行”记录。
10. 未知设备信息：固件版本、备用通道、能力在未收到状态协议数据时均为“未读取”。
11. 蓝牙配置通道多分片逐帧回调后发送、写入失败、中断和无回调超时后的重试。CoreBluetooth 适配层的状态机由逻辑测试覆盖，服务、特征、通知和配对状态仍需真机验证。
12. 应用目录扫描：顶层与嵌套 `.app` 发现、显示名称回退、同 Bundle ID 去重、无 Bundle ID 候选项区分和扫描目录优先顺序。测试使用临时目录，不读取用户真实应用程序目录。
13. 工具登记：直接系统工具标识唯一且稳定；快捷指令模板名称与产品规格一致。不得以自动化测试实际锁屏、改壁纸、改音量或控制 Music。
14. 主窗口协调：菜单栏命令、Dock 重新打开和应用重新激活复用同一显示请求；无可见窗口时恢复一个主窗口，不创建重复窗口。
15. 应用显示信息：已登记应用可从有效安全书签解析图标；书签失效时回退为通用图标，不写入或显示绝对路径。
16. 输入预设：固定文本、组合键预设的版本化读写和旧数据迁移；选择预设后值复制到控制件，编辑或删除预设不改写既有控制件快照。
17. 组合键录制：修饰键排序、常见字母数字、空格、方向键、Tab、Return、Escape、Backspace 和 F1-F12 的规范化；仅修饰键、Fn、媒体键和未映射键位不得保存。
18. 偏好与权限：菜单栏开关默认值、登录项服务返回状态、辅助功能显式请求与重新激活复查；自动化状态只由实际执行结果更新。测试使用可注入服务，不注册真实登录项或更改系统权限。
19. T05 状态请求：`0x13 / S3R v1` 的 magic、版本、非零 request ID、fresh 标志和保留字节；包含或不包含 Report ID 的宿主缓冲区边界。
20. T05 状态响应：`0x11 / kind 0x04` 的分片重组、request ID 匹配、分片顺序/总数、JSON 长度、CRC16、未知 schema、超时和旧响应替换；任何失败不得覆盖上一次已校验快照。
21. T05 能力消费：只读取 `ai_keyboard.config_status.v1` 已存在字段；`semantic_actions=true`、false、缺失和未知时的 UI 状态；语音和编辑按住说话还需同时读取 `ptt_hotkey` 与 `edit_ptt_hotkey`。音频诊断不得启用灯光或音乐律动能力。
22. T05 前台应用规则：规则版本化读写、缺失 Profile、空 Bundle ID、同一应用的重复启用规则、启停与移除；规则不得保存应用路径或安全书签。
23. T05 自动切换：前台应用匹配、自动切换关闭、已选相同配置档、设备未连接、本地尚未保存、同步进行中、750 ms 防抖重置和手动同步抢占。测试使用可注入时钟和传输适配器，不连接真实设备。
24. T05 本机工具与更新：五个内建组合键预设的规范值；喝水提醒 1 至 1440 分钟、默认 30 分钟、仅实际执行后更新通知状态；清洁屏幕遮罩关闭路径；清空废纸篓取消不执行、确认才请求 Finder；GitHub Release 检查解析公开列表，正式包忽略预发布、Beta 包包含预发布，只识别带对应 SHA-256 的 `arm64` DMG 外部链接；不下载、替换或启动应用。
25. 同步来源与连接状态：确认必须来自本次写入通道；异通道确认只记录为忽略并继续等待原通道确认；同通道但 `saved/bytes/CRC` 不一致必须失败。USB 拔出后仍存在的 BLE HID 输入不得伪装为可写 BLE 配置通道；PTT 字段缺失时通用语义动作可用，对应 PTT 动作不可用。当前 `0x03` 不含事务 ID，同通道且内容完全相同的历史回执无法仅靠桌面端完全区分，作为既有协议限制保留到实机记录中。

## UI 检查

在 `1280 x 800` 与 `1120 x 720` 分别截图检查主要页面和侧栏辅助页面。窗口小于最小尺寸不作为适配目标。

Debug 构建可使用 `--ui-state <名称>` 载入固定截图状态：`disconnected`、`connecting`、`sync-sending`、`sync-confirmed`、`sync-failed`、`empty-actions`、`permission-denied`、`long-names`、`old-firmware`、`semantic-actions-unavailable`、`script-missing`、`automatic-syncing`、`rule-conflict`、`no-results`。该入口不编入 Release 产物，不连接设备、不读取用户本地数据。

- 状态总览：未连接、连接中、USB、蓝牙配置通道、同步中、同步失败、同步确认、无本机动作记录与长名称截断。
- 配置档：顶部配置档选择器、新建配置档、`4 x 2` 宏键盘、单旋钮左转/按下/右转、四种动作类型、无已登记动作、选择动作或输入预设、测试边界与锁屏二次确认。
- 动作库：应用、网址、快捷指令、直接系统工具与输入预设的筛选、登记、编辑、选择、测试和删除；应用图标、失效回退和空列表状态。
- 设备与同步：当前连接、上次确认与本次失败同时出现、回执摘要、固件版本/备用通道/能力“未读取”。
- 权限：辅助功能的未授权、授权请求、重新激活后复查；自动化的未检查与首次执行失败状态。当前页面不出现屏幕录制权限。
- 设置与关于：菜单栏显示、登录项未启用/需要系统确认、版本和构建信息；关闭菜单栏后仍可由 Dock 恢复主窗口。
- 全局：侧栏顶部显示 EasyMacBord 品牌与独立设备摘要；页面标题只在工具栏出现一次；不展示 UUID、绝对路径、安全书签或虚构的设备详情；键帽、旋钮选择区、检查器和底部操作区不重叠。
- T03 工具状态：无可用音频输出、Apple Music 自动化被拒绝、快捷指令执行失败、无匹配应用和已选应用失效均需显示或保留可操作的边界，不能改为其他目标或显示“已执行”。
- T05 动作与场景：前台应用规则管理、规则为空、重复规则、自动切换关闭、状态读取中、分片/CRC 失败、语义动作或 PTT 未确认、灯光与音乐律动不可用、750 ms 防抖、喝水提醒表单、清洁屏幕遮罩、废纸篓本机确认和 GitHub Release 列表检查/外部手动更新链接。T05 UI 仍待人工验收。

## 真机矩阵

只有收到同一份配置的保存确认后才可开始。每项单独记录条件、用户观察、时间、结果和失败层。

| 编号 | 项目 | 通过条件 |
|---|---|---|
| HW-01 | USB-only | 配置确认成功，按键触发目标动作 |
| HW-02 | 仅 BLE（HID 输入与配置通道） | 配置确认成功，按键触发目标动作 |
| HW-03 | 双连接 | 同一按键只执行一次 |
| HW-04 | 按下 | 单次按下只产生一次动作 |
| HW-05 | 松开 | 松开不重复触发 |
| HW-06 | 回归 | 复制、粘贴、快捷键、固定文本仍正常 |
| HW-07 | 本机应用 | 已选目标应用实际打开 |

任一项目未执行即为 `UNKNOWN`，不能用其余项目替代。

UI-01 至 UI-06 是桌面端界面与 macOS 行为验证，M-01 至 M-08 是 Mac 本地动作验证，HW-01 至 HW-07 是设备同步、输入和单发矩阵。三类证据相互独立；任一未执行项保持 `UNKNOWN`。固件、HID/GATT 描述符和 S3C v1 协议在本阶段不变。
